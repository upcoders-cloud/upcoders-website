# 🛠 Project Setup – upcoders-website

This document explains how to set up the project locally from scratch.

---

## ✅ Prerequisites

Before you start, make sure you have the following installed:

- **Node.js v22.14.0**
- **npm v10.9.2**
- A code editor (e.g. [VS Code](https://code.visualstudio.com/))
- Git (latest version)


### 🧰 Optional but recommended

- [Volta](https://volta.sh/) – to lock and auto-install correct Node/npm versions
- ESLint + Prettier extensions in your IDE (e.g. for VS Code)
- Tailwind CSS IntelliSense plugin

---

Switch to the `dev` branch

`git checkout dev`

Install dependencies

`npm install`

Start development server

`npm run dev`

Open your browser at [localhost:5173](http://localhost:5173)
